# Sistemas de gestión de clientes Rengifo Ltda

Plataforma centralizada para la gestión, búsqueda rápida, control tributario, histórico de pagos/formularios y exportación (Excel/PDF) de clientes de **Rengifo Ltda**.

## Despliegue con Docker

```bash
docker compose up -d --build
```

La aplicación queda disponible en `http://localhost:3005`.
